# ДМБ Таймер ZYNT v8

Мобильный ДМБ-таймер в формате PWA. Проект рассчитан на GitHub Pages и установку на телефон как приложение.

## Что есть сейчас

- Профиль военнослужащего: имя и дата призыва.
- Срок службы автоматически считается как 1 год.
- Таймер до дембеля с процентом прохождения службы.
- Прошедшие и оставшиеся дни, часы, минуты и секунды.
- Календарь с круглыми датами и маркерами событий.
- Автоматические события: призыв, 100/200/300 дней после призыва, 100/200/300 дней до дембеля, четверть службы, времена года, Новый год, дембель и 100 дней после дембеля.
- Пользовательские события: тема + дата + сохранение.
- Пользовательские события отображаются в календаре, деталях выбранной даты и списке «События» и сохраняются после перезапуска.
- Свой фон приложения на всех вкладках.
- Редактор собственного фона: после выбора изображения открывается кадрирование под экран. Картинку можно двигать и масштабировать перед сохранением.
- Сохранённый фон уже обрезан под выбранное соотношение сторон, поэтому при обычном отображении чёрных полос из-за исходных пропорций нет.
- Фон сохраняется локально на устройстве. Файл не нужно загружать в GitHub.
- Реклама `assets/ad.png` показывается один раз после первого заполнения профиля на 15 секунд.
- PWA manifest и Service Worker.
- Нижняя навигация: Таймер / Календарь / События / Профиль.
- Чат отсутствует.
- Внизу каждой вкладки есть скрытая подпись `MY LOVE 21.12.2024`: она появляется только после вытягивания страницы дальше нижнего края.

## Свой фон

1. Открой **Профиль**.
2. Нажми **Выбрать** в блоке «Свой фон таймера».
3. Выбери изображение.
4. В редакторе перетащи изображение так, как нужно.
5. Ползунком настрой масштаб.
6. Нажми **Сохранить фон**.

Редактор использует пропорции экрана текущего устройства. Изображение сохраняется уже в подготовленном виде и используется как фон всего приложения.

## Реклама

Положи рекламную картинку сюда:

```text
assets/ad.png
```

Имя файла должно быть именно `ad.png`.

## GitHub Pages

В репозитории открой:

**Settings → Pages → Deploy from a branch → main → / (root)**

После публикации используй HTTPS-адрес GitHub Pages.

## Полная замена файлов на GitHub

Если нужно заменить проект новой версией, не обязательно удалять репозиторий.

Самый простой вариант:

1. Открой репозиторий.
2. Удали старые `index.html`, `manifest.webmanifest`, `sw.js`, `README.md` и содержимое `assets`, которое нужно заменить.
3. Нажми **Add file → Upload files**.
4. Перетащи новые файлы и папку `assets`.
5. Нажми **Commit changes**.

Можно также заменить каждый файл прямо через **Edit → Commit changes**, но для полной версии удобнее удалить старое содержимое и загрузить новый комплект.

После обновления подожди, пока GitHub Pages пересоберёт сайт, затем сделай жёсткое обновление страницы (`Ctrl+F5` на ПК). На телефоне иногда требуется полностью закрыть установленное PWA и открыть его снова, чтобы обновился Service Worker.
