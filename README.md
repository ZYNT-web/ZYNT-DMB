# ДМБ Таймер ZYNT v6

Добавлены пользовательские события календаря.

В календаре есть форма:
- тема события;
- дата;
- кнопка «Сохранить».

После сохранения:
- событие появляется в календаре;
- на дате появляется маркер;
- нажатие на дату показывает событие;
- событие появляется в общем списке событий;
- событие сохраняется локально на устройстве.

Пользовательские события хранятся вместе с профилем в localStorage.
Фон по-прежнему хранится в IndexedDB.
