# DMB Timer ZYNT 🇷🇺

**DMB Timer ZYNT** — мобильный таймер дембельского срока для военнослужащих срочной службы.

Приложение помогает отслеживать срок службы, видеть оставшееся время и важные даты, а также хранить собственные события в удобном календаре.

Проект создан как лёгкое веб-приложение, которое можно открыть с телефона или установить как приложение (PWA).

---

## ✦ Возможности

### ⏳ Таймер службы
- обратный отсчёт до ДМБ;
- количество прошедших и оставшихся дней;
- часы, минуты и секунды;
- процент прохождения службы;
- автоматический расчёт срока службы — 1 год;
- информация о дате призыва и предполагаемой дате ДМБ.

### 📅 Календарь
В календаре отображаются важные даты службы:

- 100 / 200 / 300 дней;
- четверти срока службы;
- времена года;
- Новый год;
- ДМБ;
- 100 дней после ДМБ;
- другие автоматически рассчитываемые события.

Также пользователь может создавать **свои события**:

> Тема → дата → сохранить

Созданное событие отображается в календаре и общем списке событий.

Свои события можно удалить после подтверждения. Автоматические события приложения удалить невозможно.

### 🖼 Персональный фон

Можно установить собственное изображение в качестве фона приложения.

Для изображения предусмотрен редактор:

- перемещение;
- масштабирование;
- уменьшение;
- поворот;
- кадрирование.

Если при изменении масштаба или поворота появляются свободные области, они заполняются размытым вариантом той же фотографии — поэтому чёрных полос не появляется.

Настройки фона сохраняются на устройстве пользователя.

### 📱 PWA

Приложение можно установить на смартфон как обычное приложение.

После установки оно открывается отдельно от браузера и сохраняет свои пользовательские данные на устройстве.

### 📢 Реклама

После первого заполнения профиля может показываться рекламный экран.

Рекламное изображение:


Реклама показывается один раз на устройстве.
